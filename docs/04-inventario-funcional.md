# 04 · Inventario funcional

## Objetivo
Construir una matriz AS-IS / TO-BE y decidir para cada función: mantener, rediseñar, automatizar, posponer o eliminar.

| Área | Fuente actual | Dirección |
|---|---|---|
| Blog | WordPress | Mantener inicialmente |
| Catálogo/buscador | Producción + WeWeb | Reconstruir |
| Ficha de curso | Producción + WeWeb | Reconstruir y proteger SEO |
| Landings SEO | Producción + WeWeb | Auditar y consolidar |
| Registro/acceso | WeWeb / actual a validar | Supabase Auth |
| Perfil | WeWeb / operación a validar | Rediseñar |
| Solicitudes | Airtable/manual + WeWeb | Rediseñar |
| Documentos | Manual/parcial + WeWeb | Storage privado + RLS |
| Admin cursos/entidades | Airtable + WeWeb | Backoffice nuevo |
| Convocatorias/ediciones | Airtable + WeWeb | Normalizar |
| Emails/alertas | Pendiente | Rediseñar |
| Reporting | Pendiente | Definir KPIs |

## Procesos manuales
Para cada operación registrar: disparador, entrada, herramientas, reglas, salida, excepciones, responsable, frecuencia, coste/tiempo y supervisión humana.

Clasificación final: **mantener manual / facilitar con backoffice / automatizar**.
