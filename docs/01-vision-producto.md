# 01 · Visión de producto

**Estado: pendiente de completar con el equipo.**

La dirección técnica está bastante definida, pero no debe cerrarse el modelo de datos ni el alcance definitivo antes de documentar qué queremos que sea TuFormacionImporta.

## Taller de visión pendiente

### Propósito
- Qué problema resolvemos.
- Qué transformación buscamos para el usuario.
- Qué papel queremos ocupar entre persona, entidad formadora, convocatorias y mercado laboral.

### Personas
Validar como mínimo: persona interesada en formación, desempleada, trabajadora, autónoma, entidad/centro, empresa y equipo interno.

Para cada perfil: necesidad, datos aportados, tareas, beneficios, recurrencia y permisos.

### Journey
Descubrimiento → búsqueda → evaluación → registro → solicitud → documentación → seguimiento → finalización → histórico/perfil → recomendación → retorno.

### Valor para entidades y para el equipo
Definir autonomía, gestión de leads/solicitudes, reporting, tareas manuales a mantener, facilitar o automatizar.

### Modelo económico
Documentar el actual y posibles líneas futuras sin diseñar la base de datos alrededor de hipótesis no decididas.

### IA
Evaluar extracción/clasificación documental, perfil, matching, itinerarios, CV, búsqueda semántica, backoffice y calidad de datos.

### Objetivos y métricas
Tráfico cualificado, leads, solicitudes válidas, tiempos operativos, recurrencia, cobertura de catálogo e indicadores económicos.

## Entregable
Documento de visión 3-5 años + mapa de personas + journeys + objetivos.
