# ADR-006 · n8n para automatizaciones periféricas
- **Estado:** Aceptado como principio.
- **Fecha:** 30/09/2026

## Decisión
Usar n8n para integraciones y automatizaciones periféricas. Mantener la lógica crítica en código, base de datos, RLS y funciones controladas.

## Consecuencia
Cada automatización deberá clasificarse como core o periférica antes de implementarse.
