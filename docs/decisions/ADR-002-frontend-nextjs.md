# ADR-002 · Frontend: Next.js + TypeScript
- **Estado:** Aceptado.
- **Fecha:** 30/09/2026

## Decisión
Desarrollar el frontend objetivo en Next.js + TypeScript, versionado en GitHub y desplegado inicialmente en Vercel.

## Consecuencias
WeWeb se conserva como referencia funcional/visual. No se migran páginas 1:1: se migran capacidades y patrones.
