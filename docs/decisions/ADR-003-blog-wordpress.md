# ADR-003 · WordPress se mantiene como flujo editorial
- **Estado:** Aceptado para la primera fase.
- **Fecha:** 30/09/2026

## Decisión
Mantener WordPress para el blog y la publicación editorial.

## Consecuencias
No se implementa headless por defecto. La convivencia de rutas se decidirá tras auditar SEO. Headless queda como opción futura.
