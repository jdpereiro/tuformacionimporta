# ADR-005 · Xano: fuente histórica, no runtime futuro
- **Estado:** Aceptado.
- **Fecha:** 30/09/2026

## Decisión
No reactivar Xano como plataforma objetivo. Auditarlo como fuente histórica de datos, relaciones y lógica.

## Alcance de auditoría
Tablas, relaciones, índices, endpoints, funciones, autenticación, reglas, plantillas, almacenamiento y formatos de API.
