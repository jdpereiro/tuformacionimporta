# 06 · SEO y WordPress

## Decisión
Mantener WordPress como flujo editorial del blog en la primera fase. No convertirlo a headless por defecto.

## Auditoría necesaria

### Search Console
URLs y consultas con valor orgánico, clics, impresiones, posición, CTR, indexación y sitemaps.

### GA4
Landing pages, tráfico, comportamiento y conversiones/leads.

### WordPress
Posts, páginas, slugs, categorías/tags, tipos de contenido, plugins SEO, canonicals, redirects, sitemaps y medios.

### Crawl público
Enlaces rotos, redirecciones, huérfanas, duplicidades, canonical y profundidad.

## Principios
- Conservar URLs valiosas.
- Redirects 301 verificados cuando cambien.
- Staging y filtros sin valor fuera de indexación.
- Control explícito de canonical, sitemap y robots.
- Datos estructurados cuando proceda.
- Comparar métricas antes/después del corte.

## Futuro posible
WordPress podría convertirse en CMS headless si la unificación compensa el coste operativo. No es un requisito actual.
